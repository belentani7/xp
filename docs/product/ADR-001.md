# ADR-001 — Distribución y hooks de XP

Estado: aceptada para esta entrega.

XP seguirá siendo local y stdlib-only. Se publica como paquete Python con entrada `engine.cli:main`; SQLite y sus migraciones se incluyen como recursos de paquete. La vinculación con Git es opt-in por repositorio (`xp install-hooks`) y no instala configuración global. Los hooks se ejecutan con el intérprete que instaló XP y silencian fallos propios para no bloquear operaciones Git.

Se elige esta solución porque elimina rutas relativas del checkout y permite quitar la integración de un repositorio concreto. Cuenta local, telemetría y servicios remotos quedan fuera.
