Empieza en dos pasos

Instálalo. Activa un repo. A jugar.

Requiere Python 3.7 o posterior y Git. La instalación no añade dependencias de ejecución.

python -m pip install git+https://github.com/belentani7/xp.git

Después, inicia tu personaje y habilita la integración solo en el repositorio actual:

xp init --name Ada
cd mi-proyecto
git init
xp install-hooks
xp status

Local por diseño

Tu progreso se queda contigo.

El personaje y el historial se guardan en SQLite dentro de ~/.xp/. XP no crea cuentas, no envía telemetría y no necesita una conexión para jugar.

Los hooks son opcionales y se instalan por repositorio. Puedes retirarlos en cualquier momento con xp uninstall-hooks.

Preguntas frecuentes

Antes de empezar.

¿Funciona en Windows?

Sí. XP es una aplicación Python con SQLite y funciona en Windows, macOS y Linux. La integración de Git se instala por repositorio con el comando xp install-hooks.

¿Qué hace falta instalar?

Python 3.7 o posterior y Git. Para instalar XP se usa pip; el programa no requiere paquetes externos al ejecutarse.

¿Cómo dejo de usar los hooks?

En el repositorio donde los activaste, ejecuta xp uninstall-hooks. XP solo elimina sus propios hooks.
